# Routeweave
A data management and route planing project for dynamic road networks

## 小组协作入口

本项目采用五人分工，研究动态路况下的园区路径查询数据管理设计。

- [AI 协作指南：AGENTS.md](AGENTS.md)：共同口径、五人分工、协作边界与交接要求。
- [agent.md 入口](agent.md)：按该文件名查找时进入统一指南。
- [Zoran 的工作与交接记录](docs/handoffs/zoran.md)：已完成内容、成果路径、验证结果及下一步。
- [其他成员的交接模板](docs/handoffs/TEMPLATE.md)：复制后填写个人实际进度。
- [原始五人分工方案](地图路线小组作业_五人分工方案.docx)：场景、详细任务、交付物和课程要求记录。

每位成员及其 AI 开始工作前阅读 `AGENTS.md` 和相关个人记录，完成工作后同步更新成果与交接记录。角色认领情况以分工表中的确认信息为准。
