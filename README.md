# Routeweave
A data management and route planning project for dynamic road networks

## 小组协作入口

本项目采用五人分工，研究动态路况下的园区路径查询数据管理设计。

- [作业要求核对记录](docs/requirements-audit.md)：正式要求、来源页码与交付对照。
- [最新五人任务清单](docs/team-tasks.md)：当前技术责任、个人交付物、验收标准与交叉检查安排。
- [AI 协作指南：AGENTS.md](AGENTS.md)：共同口径、五人分工、协作边界与交接要求。
- [agent.md 入口](agent.md)：按该文件名查找时进入统一指南。
- [其他成员的交接模板](docs/handoffs/TEMPLATE.md)：供后续新增或调整记录时使用。

每位成员及其 AI 开始工作前阅读 `AGENTS.md` 和相关个人记录，完成工作后同步更新成果与交接记录。当前分工以最新任务清单为准，个人进度记录使用成员缩写。
