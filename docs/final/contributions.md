# 成员贡献比例与依据

依据 2026-11-07 各成员的任务记录（`docs/handoffs/*.md`，保存在 `develop` 分支）、模块成果、测试与实验结果、审阅与修复日志，按下列方法确定比例，并填入《团队项目贡献度确认表》。仓库只使用缩写；正式表上的姓名、学号与签字由成员本人填写。

## 计算方法

四个维度加权，每项 0–10 分，按加权得分归一为百分比并取整（合计 100%）：

| 维度 | 权重 | 计入的记录 |
| --- | --- | --- |
| 本人模块与章节 | 35% | v1 模块设计文档与 v2 负责章节的范围、深度与篇幅 |
| 实现与实验 | 25% | 原型代码、测试、实验脚本与结果文件 |
| 审阅与修复 | 15% | 逐棒审阅发现的问题、本人问题的修复 |
| 整合与协调 | 25% | 跨模块整合、统一模式、报告与 PPT 整合、协作流程 |
