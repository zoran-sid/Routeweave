## 正式表填写步骤

1. 全员核对上述成果及各自交接，确定实际贡献比例，合计100%。
2. 在课程提供的正式表格填写姓名、学号及贡献比例；身份字段由成员本人提供。
3. 每名成员所在行由团队全体成员签字；人数不足时多余签名栏可留空。
4. 按正式提交通知保存签署版本，并与报告、PPT一起交给小组确认的提交负责人。

仓库未代填百分比、学号、签名或成员认可。报告第10节已记录AI辅助检索、比较、写作、实现、测试及整合的实际使用方式；成员仍需审核本人负责内容并满足课程正式声明要求。
