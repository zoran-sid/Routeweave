# 地面风险评估与安全治理：报告章节

## 1. 研究问题与风险含义

SkyRoute 的调度员需要判断一条航线经过的地面区域是否适合配送，并在候选航线间比较效率与人员暴露。距离较短的路线可能经过商业热点，增加对地面人员的潜在影响。本模块把风险评价作为版本化的数据服务：给定完整三维航段、任务时间窗及输入版本，返回允许、禁止或未知，以及指标、来源和原因。

地面人员风险的因果链包括飞行失效、坠落或偏离后的影响位置、影响范围内的人员暴露，以及撞击后的后果。人口密度只覆盖其中一个因素。EASA 对地面风险的说明同时涉及人口、无人机尺寸和缓解措施等条件[1]。本项目据此区分三个层次：物理风险概念、用于模拟的可计算代理、由治理流程批准的使用条件。无人机机型、风、坠落分布和伤害数据尚未给定，因此本模块采用可解释的代理支持设计验证。

若未来获得校准数据，可以对每条航段建立“失效概率 × 条件落点分布 × 暴露 × 条件伤害”的积分模型，并说明多次失效及人员重复暴露的相关性。当前不输出预期伤亡人数或事故率。研究[2]表明采用具有时间变化的人口分布会改变风险分析结果，因而风险数据需要保留有效时间、空间精度与来源。本文只借用其时空建模动机，实验数据完全合成。

## 2. 模型选择与计算

| 候选方案 | 数据需求与代价 | 本模块结论 |
| --- | --- | --- |
| 仅按人口密度排序 | 输入少，但忽略机型、影响范围、后果和缺失数据 | 不足以解释本项目风险 |
| 概率化期望损失 | 需要失效率、落点核及条件伤害模型，可给出有量纲的期望损失 | 后续校准方向，当前证据不足 |
| 后果加权暴露代理 | 明确暴露、后果、包络和适用场景，容易复核并兼容现有规划接口 | 当前采用，保留全部输入及模型版本 |

### 2.1 输入与单位

沿用 `starter-v0`：局部米制坐标，x向东、y向北、z向上，平地 z=0。复用 ZC 的100×100米水平域、10–70米中心高度、10米网格、2米障碍包络、10米/秒恒速及固定模拟任务时间。地面影响包络独立取航段水平投影各轴向外扩展5米，闭边界接触也算相交；几何采用完整航段检查。高度增加不会在这个简化模型中自动降低地面风险。

定义归一化暴露 E 和条件后果系数 C，二者均为[0,1]内的无量纲合成量。E并非未经转换的人/平方千米，C也未经校准为死亡概率。背景取 E=0.1、C=0.5，得 q=0.05；商业区取 E=0.875、C=0.8，得 q=0.70。区域空间范围为 x∈[30,70]、y∈[35,65]。这些值用于对照，不来自实测或监管阈值。

```text
q(region, period) = E × C
q_max(edge) = max(背景q, 所有相交区域在任务窗内的已知q)
r(edge) = length_3d(edge) / 100m × q_max(edge)
R(route) = sum(r(edge))
J(route) = sum(length_3d(edge)/100m + lambda × r(edge)), lambda >= 0
```

R是按航程累计的后果加权暴露代理，可以大于1。它不具有概率含义。固定机型及单位航程失效倾向相同的假设被吸收到权重，改变机型、速度或风条件需要新模型。采用单位航程代理而非随时间的失效率，与当前恒速比较兼容，但不支持把长时间悬停视作零风险的真实飞行决策。

### 2.2 时间、重叠和未知

对每个区域保留半开有效区间。适配层计算整个任务窗内的最大已知q，逐区合并有效区间检查时间覆盖；任何缺口或未知E/C都会生成未知标记。恰好在窗口结束时生效的新记录不参与本次计算。多区域重叠用最大值，避免重复统计同一人群；这相对每条航段中最大的输入q偏保守，但并非真实伤害风险的数学上界。它也会覆盖整段长度，网格细化可能改变代理总量，所以只比较相同离散精度、同一版本下的结果。

若已知 q≥0.9，航段禁止；否则若影响包络命中未知区域，返回未知；其余航段允许。已知危险和未知并存时，已知硬约束足以拒绝该航段，来源中仍保留未知标识。未知区域能被绕开时允许返回已知子图上的可行路线，不能声称它是包含未知区域的全局最优解。整窗最大值可能排除在低暴露时段可通过的路线，精细时间扩展搜索属于未来改进。

### 2.3 硬约束与偏好

硬阈值0.9是演示规则。阈值及影响半径由风险模型版本记录，安全评审员负责审核；优化权重lambda只表达可接受范围内的偏好。即使lambda=0，硬约束仍然有效。固定尺度100米保证结果不会随候选路线集合变化。已知允许边的代理可加、非负，与ZC的欧氏长度启发式兼容。累计风险上限若成为新的硬约束，则需要多标签或扩展状态搜索，不能在当前单标签结果上声称已解该问题。

## 3. 风险数据管理与查询

风险模块向YHT提供的是字段语义，不指定整个项目的数据库产品。推荐关系模式如下，具体外键及空间类型可由YHT映射：

| 实体与键 | 主要字段 | 质量与血缘规则 |
| --- | --- | --- |
| exposure_profile `(dataset_version, region_id, valid_from, record_id)` | 水平几何、有效截止、E、C、source_id、received_at、分辨率、质量状态 | 时间非空且有时区，E/C有限且位于[0,1]，缺失显式记录，记录ID允许同窗多来源 |
| risk_model `model_version` | 公式、聚合、影响半径、阈值、机型假设、参数摘要 | 发布后不可变，参数变更创建新版本 |
| source_catalog `source_id` | 合成/公开类别、许可、采集方法、参考日期、内容摘要 | 限制用途，内容和摘要对应 |
| risk_assessment `assessment_id` | query_id、五类版本、窗口、完整航段、状态、q_max、r、原因 | 引用实际读取版本，失败指标为空，保存必要解释 |
| audit_event `event_id` | actor、角色、动作、对象版本、前后摘要、时间、结果、correlation_id | 成功与拒绝均记，限制修改，保留期由课程模拟策略说明 |

Q1批量加载固定发布版本与覆盖范围，编译风险层后进入规划；Q2依据航段标识或坐标、任务窗与五类版本返回风险状态和来源。`results/evaluation.json`包含实际航段响应与路线。默认完整背景是合成夹具的显式假设，真实区域覆盖缺失必须先标记 `complete=false`，不能沿用背景推断安全。

接入源存储时可用空间索引筛选与地面影响包络相交的候选记录，再检查有效时间和精确几何。按数据版本及日期组织记录，风险派生层缓存键至少含五类版本、窗口、影响半径和离散配置。风险更新定位采用地面投影，不能因无人机飞得较高而跳过低高度风险区域。来源撤销、q下降和模型参数改变都可能改变最优路线。

## 5. 反思与下一步

当前小场景验证了规则可计算、缺失数据不会自动变安全、硬约束无法被效率收益抵消，以及接口可与既有规划组合。它不能估计真实城市的失效率、落点、遮蔽或伤害结果。下一步应核对输入误差，比较5米与更大包络、10米与更细网格，按区域报告风险负担，使用多时段暴露数据，并在真实数据库上验证权限与审计。不同地图精度和时效带来的查询成本，应与推荐质量一起测量。
