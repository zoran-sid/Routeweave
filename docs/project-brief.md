# SkyRoute — 面向城市无人机配送的时空数据管理系统设计

**英文名称：** SkyRoute: Spatio-temporal Data Management for Urban UAV Delivery

## v2 定位（2026-11-06）

v1（标签 `v1.0-algorithm-baseline`）以航线算法为主线。课程要求的是数据管理系统设计，v2 以数据库为中心：统一模式、时空查询与索引、事务与版本、治理与访问控制、恢复验收是主线；航线规划是验证数据库设计的业务场景。以下背景、用户、功能与范围继续有效；技术研究方向和核心研究问题按 v2 更新。分工见[任务安排](https://github.com/zoran-sid/Routeweave/blob/develop/docs/team-tasks.md)。

## 一、项目背景

随着低空经济与城市无人机物流的发展，无人机配送需要面对复杂的空间环境。城市中的高层建筑、密集住宅区、道路、桥梁及不同高度的障碍物，使航线规划需要处理三维空间中的可通行性。

无人机还需要考虑动态空域限制、人口密集区域、地面人员安全及潜在坠落风险。距离最短的航线未必是最安全或最适合执行配送任务的航线。

SkyRoute 旨在探索如何结合城市三维空间数据、动态空域信息和路径规划算法，构建兼顾**配送效率、空域安全与地面风险**的无人机航线查询与数据管理系统。

## 二、项目目标

1. **城市三维环境建模**：利用建筑物高度、地形、城市基础设施等空间数据，构建适用于无人机航线查询的三维环境模型。
2. **动态空域数据管理**：管理临时禁飞区、限高区域、空域状态变化及其生效时间，保证数据更新的一致性和可追溯性。
3. **地面安全与风险评估**：结合人口密度、学校、医院、商业街及其他人员密集区域等数据，建立用于航线规划的地面风险评估机制，研究潜在失效或坠落事件对地面人员的影响。
4. **多约束三维航线规划**：在满足建筑避障、飞行高度、禁飞限制等硬约束的前提下，综合考虑航程、飞行时间和地面风险，寻找适合城市配送的航线。
5. **数据管理与性能优化**：研究空间数据存储、索引、动态更新、版本管理及查询性能，比较不同数据库技术和路径规划方法的适用性。

## 三、目标用户

- **无人机物流调度员**：创建配送任务、查询航线并评估配送效率与风险。
- **无人机运营人员**：查看三维航线、空域限制和风险信息。
- **空域及安全管理员**：维护禁飞区、空域限制、风险区域及相关数据。
- **系统管理人员**：负责权限控制、数据质量、操作审计和系统维护。

## 四、核心系统功能

- **三维航线查询**：根据配送起终点，查询满足空间及空域约束的无人机航线。
- **城市障碍物识别**：识别建筑物、地形及其他已建模障碍对航线的影响。
- **空域动态管理**：支持空域限制的发布、更新、失效及历史追溯。
- **地面风险感知**：根据人口密度和地面敏感区域等数据，为候选航线提供风险评估，并对不可接受的风险设置硬约束。
- **动态路径重规划**：在空域或风险数据变化后，重新评估并更新推荐航线。
- **数据查询与审计**：支持航段状态、风险来源、历史版本和查询结果追溯。

## 五、技术研究方向

项目以数据管理系统设计为核心：统一的时空数据模型与约束、三维空间与时间索引、事务与并发控制、版本与历史快照、数据质量与血缘、数据库访问控制与审计、备份恢复与一致性核验。

新兴技术深入讨论数据血缘与版本化派生数据管理：来源依赖、更新后的失效定位、派生数据重建成本与存储取舍；湖仓快照/时间旅行与 PostgreSQL 时态表作为比较对象。

主要证据是本地 SQLite 上的数据库实验：执行计划与索引前后访问成本、并发发布冲突、更新可见性、历史版本存储开销、恢复后完整性，以及固定 A* 时规划查询的数据库查询、装载、构图和搜索耗时分解。v1 的 Dijkstra 与 `3D A*` 对照保留为应用效果验证。地面风险作为带模型版本的派生数据集管理；人口密度是相关输入之一，不能单独作为航线安全的判据。

## 六、研究范围与预期成果

研究对象为一个具有高层建筑、商业区、住宅区及人员密集区域的**模拟城市片区**。

研究覆盖城市三维空间数据管理、动态空域限制、地面人员风险和多约束航线查询。成果用于模拟数据上的设计、查询和验证；真实无人机飞控、实时自主避障与实际飞行部署在本项目范围之外。

预期形成完整的需求分析、数据模型、系统架构、技术选型、航线查询方法及验证方案，并根据项目进度选择性开发三维可视化或模拟原型。

通过不同城市密度、建筑高度、禁飞限制和地面风险情境，评估航线可行性、查询效率、数据一致性及风险权衡。性能与风险数值依据实际实验或明确标注的模拟假设记录。

## 七、项目核心研究问题

**城市三维空间、动态空域和风险数据持续变化时，如何设计一个支持高效时空查询、一致性发布、历史追溯和安全访问的数据管理系统，为航线规划提供可靠输入？**
