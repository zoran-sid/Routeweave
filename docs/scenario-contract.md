# SkyRoute 共同场景与查询约定

本文件统一数据、约束和查询的含义。具体技术架构、空间表示、风险模型、数值参数和算法组合均在研究中论证后确定。

## 模拟场景与三类数据

研究一个包含高层建筑、商业区、住宅区及人员密集区域的模拟城市片区；可加入地形、桥梁等已建模障碍。先采用可解释的小场景，再按需要扩大规模。

| 数据 | 主要内容 | 共同约定 |
| --- | --- | --- |
| 城市三维环境 | 建筑物、地形、桥梁及其他障碍 | 坐标参考系、垂直基准、单位、精度、来源及场景版本 |
| 动态空域 | 临时禁飞体、限高区域、发布与撤销事件 | 水平及高度范围、有效起止时间、接收时间、来源和发布版本 |
| 地面暴露与风险 | 人口分布、学校、医院、商业街等区域及派生风险层 | 时空分辨率、来源、风险定义、模型参数、版本和不确定性 |

YHT 整理数据与质量说明，LQ 定义风险语义，ZQO 协调版本和访问接口，ZC 使用一致的数据进行规划，LJ 配合质量异常与运行验收。

## 空间、时间与版本

- 计算前统一坐标、高度基准和单位。未知高度、过期空域信息和缺失风险数据需要显式处理，不能自动当作零高度、无限制或零风险。
- 可行性检查覆盖完整三维航段和约定的安全缓冲范围，并明确实体内部、表面和边界的语义；只检查端点或二维投影不能完成本项目的避障判断。
- 查询明确规划时刻、预计出发时间和规划时间窗。对窗内已知生效限制，选择预计通过时间检查或整窗保守处理等适用策略，并记录依据。
- 一次结果绑定一致的场景、空域、风险输入、风险模型及规划配置版本。固定快照用于读取一致性，时间有效性仍需单独判断。
- 数据更新后重新验证受影响的推荐航线，并按新发布版本重规划。研究范围为模拟与推荐结果更新，实际飞控与实时自主避障不在范围内。

## 约束与风险

建筑避障、飞行高度、有效禁飞限制及已定义的不可接受风险属于硬约束。距离、预计时间、能耗代理量和可接受范围内的风险用于比较可行航线；优化收益不能抵消硬约束违反。

风险分析需要明确失效或坠落假设、可能的影响范围、人员暴露与后果，以及数据的不确定性。人口密度和敏感区域标签是输入，不能直接等同于安全性或伤亡概率。相对风险评分、真实概率和实测结果分别标记；阈值是待论证的模拟参数。

多指标比较说明单位、归一化、聚合方式和参数。候选路线保留目标分量及取舍解释，综合分数不作为实际飞行安全证明。

## 两项核心服务

| 服务 | 输入 | 输出 |
| --- | --- | --- |
| Q1 三维航线查询 | 起终点三维位置、出发时间、规划窗、任务约束和目标配置 | 三维航线、可行性或无法确定的原因、距离与时间、风险分量、数据及模型版本 |
| Q2 航段或区域状态与来源查询 | 三维航段或区域、时刻或时间窗、数据版本 | 障碍与空域限制、有效时间、风险及来源、发布与审计信息 |

## 算法与验证口径

Dijkstra 与 `3D A*` 在相同三维表示、约束、目标和版本上比较。ZC 说明代价与启发式的适用条件；`D* Lite` 作为动态更新候选，先论证可复用状态和变化类型。不同模型或离散精度下的结果分别解释。

验证情境覆盖建筑高度与三维障碍、有效禁飞和限高、不可行任务、风险硬约束、可行路线间的风险取舍，以及更新、数据质量和版本一致性。扩大场景时改变城市密度、建筑高度、空域限制和风险分布，记录可行性、查询与重规划耗时、更新可见延迟和资源成本。未运行的实验保留为方案。

## 技术资料入口

- [PostGIS ST_3DIntersects 官方文档](https://postgis.net/docs/ST_3DIntersects.html)：提供三维相交谓词、支持的几何类型以及二维与三维结果不同的示例。选型时继续验证具体几何和缓冲语义。
- [Koenig 与 Likhachev 的 D* Lite 论文信息](https://publications.ri.cmu.edu/d-lite)：用于研究复用已有搜索信息的增量规划，具体适用性由本项目更新模式验证。
