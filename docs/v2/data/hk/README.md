# 香港九龙实测数据快照

v2 的全部数据库实验使用本目录的香港政府开放数据，取代原先的合成城市。快照于 2026-11-07（UTC 08:41）取得，记录在 [manifest.json](manifest.json)：查询参数、记录数和每层 JSON 的 SHA-256。

## 研究区域

坐标为 HK1980 Grid（EPSG:2326，米），高度为香港主水平基准以上米数（mPD）。研究区域是以港铁旺角站（835450, 820050）为中心的三个嵌套正方形：

| 区域 | 边长 | 建筑（全部类型） | 无高度记录 | 用途 |
| --- | --- | --- | --- | --- |
| S | 250 m | 186 | 1 | 旺角核心：发布、治理与恢复实验；规划任务的起终点都在 S 内 |
| M | 1.1 km | 2,267 | 32 | 派生图缓存失效实验 |
| L | 3.3 km | 10,674 | 492 | 操作 A 访问路径实验；规划取数的最大规模 |

S、M、L 的塔楼与平台数（185 / 2,232 / 10,037）接近原合成实验的 200 / 2,400 / 10,000 栋三档规模。

## 数据来源与处理

| 图层 | 来源 | 实测 / 派生 / 假设 | 处理 |
| --- | --- | --- | --- |
| 建筑 | 地政总署“Building”（CSDI `landsd_rcd_1637211194312_35158`） | 实测 | 现存建筑的平面轮廓、底部与顶部高度（mPD）；轮廓存 WKT，规划按包围盒检查。缺少高度的开放式及临时构筑物记为 `quality='unknown'`，按全高度障碍处理，不当作安全空间 |
| 地形 | 由建筑底部高度派生 | 派生 | 网格点取 80 m 内建筑底部高度的中位数，无建筑时取最近建筑；S 区间距 50 m，M、L 区间距 100 m。地政总署 5 m 数码地形模型（DTM）的下载页面拒绝脚本访问，手动下载后可替换 |
| 限飞区 | 民航处《小型无人机令》（第 448G 章）G.N. 8002 列出的限飞区（2025-12-19 起全日生效） | 名称实测，几何派生 | 区内设施按名称前缀匹配地政总署建筑轮廓，取包围盒外扩 20 m；官方边界以民航处无人机地图为准。L 区内匹配到 8 处（旺角警署、九龙西区警察总部、深水埗警署、九龙城警署、九龙城警区总部及红磡警署、西九龙法院大楼、枪会山军营、高铁西九龙站管制站）；另 10 处在 L 区外或图层中没有对应名称，记录为未匹配 |
| 人口暴露 | 政府统计处 2021 年人口普查“大小区组”统计与边界（CSDI `censtatd_rcd_1635933282224_58228`） | 实测输入，E 派生 | E = 人口密度 ÷ L 区密度第 95 百分位（0.276 人/m²），上限 1；C = 0.5 |
| 学校 | 教育局“学校位置及资料”（数据包全部 CSDI 图层） | 位置实测，范围假设 | 以学校坐标为中心的 60 m 方格；E = 1，C = 0.95，q = 0.95 超过硬阈值 0.9，规划不得飞越 |
| 医院 | 医院管理局医院及机构名单（`facility-hosp.json`） | 位置实测，范围假设 | 经测绘处坐标转换服务由 WGS84 转为 HK1980 Grid；100 m 方格，E = 1，C = 0.95 |
| 场景限制 | `hk.scenario_restrictions` | 假设 | 发布、撤销和缓存失效实验需要的临时禁飞或限高，中心取真实建筑位置，尺寸与时段沿用原实验的分布；不是真实公告，来源记为 `SRC-SCENARIO` |

风险模型参数（C、硬阈值 0.9、5 m 影响包络）是 LQ 的演示参数，没有校准；代理值 q = E × C 不是事故概率，人口密度不等同于安全性。标准类别小型无人机的飞行高度上限为离地 300 英尺（约 91 m）；规划器的搜索域沿用 20–120 mPD，部署时应按许可高度设置。

## 复现

```bash
python3 docs/v2/data/hk/fetch.py
```

重新取得会写入新的快照与 manifest。政府数据每月更新，记录数和实验数值可能因此变化；实验默认读取已提交的快照，不联网。
